🔒 Verrouillage hebdomadaire
Les réglages s'appliquent à la semaine actuelle et suivantes. Dès qu'une semaine se termine, ses réglages sont verrouillés automatiquement 🔒.

Naviguez vers une semaine passée et cliquez "Déverrouiller pour corriger" pour rectifier une erreur.
💾 Sauvegarde des données
Données dans le localStorage de Chrome, automatiquement sauvegardées. Liées à l'URL Netlify — exportez régulièrement pour sécuriser.
🔔 Notifications
Les notifications sont programmées par minuterie précise (pas d'intervalle) sur l'heure configurée -30 min.

Elles fonctionnent avec Chrome ouvert en arrière-plan sur Android (onglet minimisé ✅). Pour les recevoir quand Chrome est fermé, un serveur push est nécessaire (non inclus).

💡 Activez les notifications via le bouton 🔔 dans l'en-tête, puis autorisez dans Chrome.
